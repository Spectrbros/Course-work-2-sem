**Для запуска:**
1) Заходим в Visual Studio

2) Нажимаем "Клонирование репозитория"

3) Вставляем ссылку на репозиторий: https://github.com/Spectrbros/Course-work-2-sem

4) Нажимаем клонировать

5) Ждём загрузку проекта и можно запускать.
<br>

**Для просмотра кода:**

1) Раскрываем справа раздел "Course work 2 sem"

2) Так же раскрываем подразделы "Файлы заголовков" и "Файлы ресурсов" 

3) Открываем нужный файл (программа разбита на 9 файлов)

4*) Смотрим, тестим, рецензируем =✪ ᆺ ✪=
